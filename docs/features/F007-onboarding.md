# F007 — Onboarding: first-use guide and starter exercises

**Status:** Planned — after register the user lands straight on the dashboard; no subtype field in `users` or `exercises`.

## Purpose

Many users arrive without knowing what Exposure and Response Prevention is. A short guide and a tailored first exercise turn a blank dashboard into a first step.

## Source

`docs/PLAN.md` → Onboarding.

## Scope

1. 3–5 step guide after first login: what ERP is, how logging works, how to rate anxiety 0–10.
2. Optional OCD subtype pick (e.g. contamination, checking, symmetry/ordering, intrusive thoughts).
3. Suggested starter exercises filtered by subtype + lowest difficulty.
4. Revisit the guide from settings/help.
